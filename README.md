# Gym Planner Web Application

## Project Overview

The Gym Planner is a web-based application designed to help users plan and track their workouts efficiently. The goal of the project was to design a user-friendly platform where gym users can organise training sessions, record exercises, and monitor their progress.
The development of this project followed a **user-centred design process**, beginning with research and design exploration before moving into development and testing.

---

# Design & Development Process

## 1. Desk Research

Initial research was conducted to analyse existing gym planning and workout websites. This helped identify useful features, layout patterns, and design approaches.

Example inspiration sites included:

* https://www.fitnessai.com/
* https://www.muscleandstrength.com/workout-routines

From this research, key insights included:

* clean and minimal UI design
* structured workout tracking
* clear navigation
* mobile-friendly interfaces

These insights informed the design direction of the Gym Planner.

---

## 2. User Personas

User personas were created to better understand the needs of potential users. Personas helped identify:

* user goals
* motivations
* pain points
* opportunities for improvement

Example persona: Alex, a 22-year-old gym enthusiast who wants an easy way to track workouts and monitor progress.
Personas ensured the design focused on real user needs rather than assumptions.

---

## 3. Sketching (Crazy 8s)

Multiple design ideas were quickly explored using sketches. This stage allowed for rapid brainstorming of possible layouts and features without spending time on detailed designs.

The sketches helped determine:

* page structure
* navigation layout
* feature placement
* overall user flow

---

## 4. Low Fidelity Prototype

A low fidelity prototype was then created to represent the basic layout of the application.

Low fidelity designs focused on:

* page structure
* content placement
* user navigation

This stage helped test usability before investing time in visual design.

---

## 5. High Fidelity Prototype

After refining the structure, a high fidelity prototype was created.

This version included:

* colours
* typography
* refined layout
* realistic UI components

The high fidelity prototype represented how the final product should look and behave.

---

## 6. Workshop & Feedback

A workshop session was conducted to gather feedback on the design. Participants reviewed the prototype and suggested improvements.

Feedback focused on:

* usability
* navigation clarity
* feature usefulness
* visual design improvements

The feedback was used to refine the interface before development.

---

# Development

## Technologies Used

The Gym Planner was developed using modern web technologies:

* HTML5 (Semantic HTML)
* CSS3
* JavaScript (ES6)

Semantic HTML was used to ensure:

* better accessibility
* improved structure
* improved SEO.

---

## Running the Project Locally

The project was served locally using a development server.

This allows the website to be viewed and tested locally during development.

---

# Testing & Performance

## Lighthouse Testing

The website was tested using Google Lighthouse to analyse performance and usability.

Tests were performed for:

Mobile devices
* Mobile devices
* Desktop devices

Lighthouse evaluated several factors:

* performance
* accessibility
* best practices
* SEO

---

## Improvements After Testing

After running Lighthouse tests, several improvements were made:

* optimised images and assets
* improved accessibility structure
* refined semantic HTML usage
* improved loading performance
* cleaned up CSS and JavaScript

These changes helped improve overall performance and usability.

---

# Conclusion

The Gym Planner project followed a structured (design → prototype → development → testing) workflow. By combining user research, iterative design, and performance testing, the final product aims to provide a clean and effective workout planning experience.

Future improvements may include:

* user accounts
* personal record (pr) tracking
* workout libary
